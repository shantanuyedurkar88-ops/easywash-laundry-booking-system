# easywash-laundryEasyWash – Laundry Booking Management System

📌 Project Overview

EasyWash is a MERN Stack-based Laundry Booking Management System designed to make laundry services easier and more convenient. Users can book laundry services online and manage their laundry orders through a simple interface.

🚀 Features

- User-friendly interface
- Online laundry booking
- Laundry order management
- Responsive design
- Frontend and backend integration
- Database management using MongoDB

🛠️ Technologies Used

- MongoDB – Database
- Express.js – Backend framework
- React.js – Frontend library
- Node.js – JavaScript runtime
- Vite – Frontend development and build tool

📂 Project Structure

- "client/" – Frontend application
- "server/" – Backend application

▶️ How to Run the Project

1. Clone the repository.
2. Install dependencies in the client and server folders.
3. Configure the environment variables.
4. Start the backend server.
5. Start the frontend development server.
